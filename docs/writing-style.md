# Documentation style

The documentation of ManimRS Studio uses ASD-STE100 Simplified Technical English (STE). STE makes
the text easy to read for persons whose first language is not English. It also makes the text easy
to translate.

Use these rules for all documentation: the README files, the files in `docs/`, CONTRIBUTING.md,
SECURITY.md and the templates in `.github/`. The rules do not apply to code comments, to the text in
the interface or to the descriptions of the MCP tools.

## Words

- Use one word for one thing. This documentation has a list of [terms](index.md#terms).
- Use the approved words of the STE dictionary, only with their approved definition.
- You can use technical names: names of files, commands, keys, buttons and programs.
- You can use technical verbs for the work of a computer: render, install, click, type, drag,
  paste, export, build, run.
- Do not use the -ing form of a verb. Write "Build the app", not "Building the app".
- Do not use contractions. Write "do not", not "don't".
- Do not use "should", "may", "might", "could" or "would". Use "must", "can" or "will".
- Do not use "need" as a verb. Write "X is necessary".
- Do not use abbreviations such as "e.g.", "i.e." or "etc.". Write "for example".
- Do not put more than three nouns together.

## Sentences

- A sentence in a procedure has 20 words or less.
- A sentence in a description has 25 words or less.
- Write one topic in each sentence.
- Use the active voice. Write "The engine renders the slide", not "The slide is rendered".
- Do not use semicolons. Write two sentences.

## Procedures

- Write each step as a command: "Click *Approve*."
- Write one instruction in each step. Two actions at the same time can be in one step.
- Write the condition first: "If the app is open, close it."
- Put a warning or a caution before the step that it is for.

## Descriptions

- Write the most important information first.
- Write one topic in each paragraph.
- A paragraph has six sentences or less.
- Use tables and lists for information that has the same structure.

## Interface text

Write the labels of the interface in italics, as the app shows them: *Render pending*,
*Send to Claude*. Write keys as the keyboard shows them: Ctrl+Enter, F2, Esc.

## Before you send a change

Read each sentence again. Count the words of the long sentences. Find the words that end in -ing.
